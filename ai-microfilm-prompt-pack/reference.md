# AI 微电影提示词包 · 参考库

配合 SKILL.md 使用。按需取用，不要把本文件整段贴给用户。

## 一、锚点词块写法规范

- 角色锚点：外貌事实按"整体→局部→服饰→姿态"顺序罗列，只用中性形容词；不含镜头、动作、情绪变化词（这些留给每镜提示词）。定稿后全片原样复制，一个字不改。
- 道具锚点（角色佩戴版）：道具形状 + 颜色 + 图案 + 佩戴方式/形态约束。形态约束词很关键（如"内裤罩住头顶"），防 AI 把道具画成帽子、面罩等错误形态。
- 道具锚点（独立设定图版）：`道具设定图，多角度：正面、侧面、顶面，` + 形状 + 材质 + 颜色 + 尺寸关系（与人/手的比例）+ 佩戴或使用方式 + 形态约束词。道具展开型故事（内裤、囍字、手、胡须类主题）必出。
- 风格锚点：媒介 + 风格名 + 线条 + 上色 + 色调 + 对比 + 线条质感 + 背景 + 无文字无水印。全片统一，不同项目按第 0 步确认的画风替换。

## 二、通用负面词库

文生图/图生视频的负面提示词统一填：

3D, 渲染, 写实, 照片, 干净平滑线条, 迪士尼风格, 吉卜力风格, 鲜艳色彩, 可爱Q版, 文字, 水印

纯环境场景图额外追加：人物, 角色, 动物

## 三、工具操作路径

- 即梦：使用"角色一致性"功能，把三视图建成角色库，每镜从角色库调用。
- 可灵：使用"多图参考"→"主体参考"，每镜上传同一张角色三视图，权重拉满。
- 通用顺序：文生图出每镜关键帧 → 肉眼确认角色没漂 → 关键帧图生视频。不要直接文生视频。

全片素材生成顺序（新项目照此执行，顺序不可调换）：

1. 文生图：角色素体三视图（全员，先过稿再往下走）
2. 图生图：道具状态版三视图（以素体图为参考图，追加道具词；同脸同服）
3. 文生图：特殊道具设定图（道具展开型故事）
4. 文生图：纯环境空镜场景图（默认不带角色）
5. 图生图：带角色场景图（仅当需锁定"角色×环境"关系时，参考对应角色图）
6. 每镜：文生图关键帧（嵌角色/道具/场景/风格锚点）→ 图生视频（只写动作词，外貌由参考图锁定）

## 九、形态分流：短视频爆款逻辑 vs 微电影五段式

用户给想法后先判断形态再选结构工具，以用户说法为准（说"短视频/十几秒"走 A，说"微电影/短剧"走 B，没说清就问）。两条路径共用同一套生成管线（三视图先行、场景空镜、每镜关键帧图生视频、去水印、归档），只有结构改造这一步不同。

共同铁律——画面优先，能演就不说（show, don't tell）：情绪、关系、冲突一律让画面演出来，字幕旁白只补画面表达不了的信息（内心独白、抽象概念、时间跳跃）。每镜自问：把字幕删掉，画面还成立吗？成立就删。

### A. 短视频（十几秒，爆款逻辑，不套五段式）

十几秒没有铺陈空间，硬套五段式会把钩子淹在铺垫里，观众三秒划走。骨架：

| 节拍 | 作用 | 改造时自问 |
| --- | --- | --- |
| 黄金三秒钩子 | 首镜即冲突/悬念/反常识/强情绪，留不住人后面全白费 | 观众第一眼看到什么会停住手指？ |
| 情绪爆点 | 十几秒只容一个爆点，情绪瞬间打到顶，不铺垫不渐入 | 哪一帧是情绪峰值？爆点前置了没有？ |
| 收尾余味 | 最后画面给情绪落点或反转，勾人重看/评论 | 看完最后一眼，观众想说什么？ |
| 转场/卡点 | 节奏靠转场和卡点驱动，不是情节推进 | 硬切、匹配转场、音效卡点落在哪几个镜头交界？ |

压缩规则：3-6 镜，每镜 2-4 秒；每镜标注钩子/爆点/转场。

### B. 微电影（1 分钟以上，五段式改造）

每段一句话 + 预估镜头数，五段齐了才写分镜。

| 阶段 | 作用 | 改造时自问 |
| --- | --- | --- |
| 1 激励事件 | 打破平静的一瞬间，改变命运，故事由此开始 | 主角原本的平静是什么？被什么打破？ |
| 2 进展纠葛 | 事与愿违，计划被打乱，阻碍不断出现，主角被迫前行 | 事情还能更糟吗？下一镜如何"再糟一层"？ |
| 3 危机 | 情绪压到最低，一切失控，陷入看似无解的绝境 | 办法用尽、没有希望的瞬间是什么？ |
| 4 高潮 | 冲突释放，主角做出选择，冲突解决，情绪转折爆发 | 主角做的那个选择是什么？代价是什么？ |
| 5 结尾 | 引发思考，留给观众一个问题，联系自己的人生 | 观众看完会问自己什么问题？ |

- 短片压缩规则：55 秒左右的微电影五段各 1-2 镜，压缩篇幅不删节拍
- 用户想法常见缺段：只有高潮没激励事件、平铺没危机。补段时明确告诉用户补了什么
- 情绪曲线由五段自然生成：平静 → 起伏 → 最低 → 爆发 → 余味

### 对照案例（喜字枷锁）

| 阶段 | 内容 | 对应镜头 |
| --- | --- | --- |
| 激励事件 | 婚礼最喜，红纸最满，囍字套头如枷（平静的喜庆=枷的起点） | 镜 1-2 |
| 进展纠葛 | 红纸变铁，扶着的手变成上锁的手 | 镜 3-4 |
| 危机 | 老一辈差一步，新娘摔倒够不到（情绪最低点） | 镜 5 |
| 高潮 | 现在也是一步，新娘选择离开（现代对照，选择即高潮） | 镜 6 |
| 结尾 | 差一步就是一辈子；黑场"最喜的字，为什么那么像枷"（引发思考） | 镜 7 + 黑场 |
