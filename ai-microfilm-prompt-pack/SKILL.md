# AI 微电影提示词包产出流程

## 适用场景

用户给出文案/主题（一句金句、一段故事、一个点子），要产出可用于即梦/可灵等 AI 视频工具制作微电影的完整提示词包。触发词示例：AI 微电影、AI 漫剧、AI 动画短片、分镜、提示词包、图生视频、三视图。

## 核心原则（用户踩过的坑，违反即返工）

1. 交付提示词，不代生成多图。AI 逐张直出会导致角色不一致；正确交付物是提示词文本，由用户在工具里跑。
2. "场景提示词"指纯环境空镜图（不含角色），不是分镜。用户要"场景"时给空镜设定图提示词。
3. 每条提示词必须完整展开、可直接复制。严禁占位符、拼装模板、待填符号。
4. 角色带关键道具时，道具状态版三视图必须单独一张，与素体版分开。
5. 一致性靠"固定锚点词块 + 参考图图生视频"两条腿，缺一不可。
6. 生成顺序硬性规定：素体三视图 → 道具版三视图（以素体图为参考图）→ 道具设定图 → 场景空镜图 →（必要时）带角色场景图 → 每镜关键帧 → 图生视频。道具版脱离素体版单独生成 = 同角色两张脸。
7. 所有成图去水印：提示词带"无文字无水印"；工具强制出水印时，后期（剪映"消除笔"/裁切/PS）处理后再入库。
8. 形态分流，不教条：先判断视频形态再选结构工具。十几秒短视频不套五段式，走爆款逻辑（黄金三秒钩子 + 情绪爆点 + 转场节奏）；微电影才做五段式改造（激励事件 → 进展纠葛 → 危机 → 高潮 → 结尾）。以用户当时的说法为准，没说清就先问。生成顺序与交付管线两条路径共用，短视频只是镜头数少。

## 工作流（六步管线）

### 第 0 步 前置确认（不可跳过）

开工前必须确认五项，缺一项就问（用 AskUserQuestion）：
- 内容路线：主题与叙事走向
- 画风：如 2D 独立手绘（Dog Days 风/吉卜力风）、厚涂、写实电影感、国漫 3D、聊斋国风等
- 画幅：16:9 / 9:16 / 21:9
- 旁白：有无、语气、人称
- 保存路径：素材根目录（`D:\视频素材\我的素材\`）下的主题文件夹名，默认 `<短剧名>`，沿用 人物/道具/场景/镜头/旁白/成片 分类（见「素材目录规范」）

画风确认时先查风格库 `~/.qoderworkcn/skills/style-*`：用户点名的风格若有对应技能（如"聊斋风/画皮风/画心月狐风" → style-liaozhai-guofeng），加载该技能，直接采用其风格锚点词块与负面词库，并在交付文件里注明风格来源。没有对应技能时，按 reference.md 拆解规范从用户给的参考图/参考视频拆风格，交付完成后询问用户是否沉淀为新风格技能。

同时告知交付物为哪几个 md 文件。

### 第 1 步 形态分流 → 结构改造 → 分镜脚本

先判断形态，以用户说法为准（用户说"短视频/十几秒"走 A，说"微电影/短剧"走 B，没说清就问），不按教条猜：

**A. 短视频（十几秒，爆款逻辑，不套五段式）**

骨架 = 黄金三秒钩子 → 情绪爆点 → 收尾余味：

1. 黄金三秒：首镜必须给冲突/悬念/反常识/强情绪，观众前三秒留不住后面全白费。问清"第一眼看到什么会停住"
2. 情绪爆点：十几秒只容一个爆点，情绪在爆点瞬间打到顶，不铺垫不渐入
3. 收尾余味：最后一个画面给一个情绪落点或反转，让人想重看或想评论
4. 节奏靠转场/卡点驱动，不是情节推进：镜头间用硬切、匹配转场、卡点音效制造爽感

每镜标注钩子/爆点/转场，压缩规则：3-6 镜，每镜 2-4 秒。

**B. 微电影（1 分钟以上，五段式改造）**

先按五段式结构改造用户的想法，每段给一句话 + 预估镜头数，等用户确认后再写完整分镜：

1. 激励事件：打破主角平静生活的一瞬间，改变命运，故事由此开始。想清"平静是什么、被什么打破"
2. 进展纠葛：事与愿违，计划被打乱，阻碍不断出现，主角被迫前行。每镜让事情"更糟一层"，不重复同一层面
3. 危机：情绪压到最低，一切失控，主角陷入看似无解的绝境，仿佛办法用尽没有希望
4. 高潮：冲突释放，主角做出选择，冲突解决，情绪转折爆发
5. 结尾：引发思考，留给观众一个问题，让人联系自己的人生

短片压缩规则：55 秒左右的微电影五段各 1-2 镜；压缩的是展开篇幅，不是结构节拍，五段都必须在。用户想法缺段（常见缺"激励事件"或"危机"）就补出来，并明确告知补了什么。五段式改造稿连同分镜一起交付，分镜每镜标注对应阶段。

结构确认后按时间线切镜，每镜包含：镜头号·标题（时间码起止）·结构标注（短视频标钩子/爆点/转场，微电影标五段阶段）、画面描述、运镜、字幕、音效。时间码累计递增，后续配音稿与此对齐。分镜全文等用户确认再进入下一步。

### 第 2 步 角色三视图提示词

- 素体版：`角色设定图，三视图：正面、侧面、背面，` + 完整外貌描述（毛色/耳/眼/鼻/表情/体型/四肢/服装/姿态） + `站姿，双手自然下垂，` + 风格锚点 + `纯浅灰背景，无文字无水印`
- 道具状态版：在素体版基础上叠加道具形态约束词（如"内裤罩住头顶"），约束 AI 别把道具画错形态（帽子化/面罩化）。说明侧背面视角道具位移是正常的，正面图才是锚定关键帧。
- 两版都要出：素体版供动作参考与"未装备"镜头，道具版供核心镜头。
- **生成顺序（硬性）**：先文生图出素体版 → 肉眼确认不漂 → 把素体版图作参考图（即梦"角色一致性" / 可灵"多图参考·主体参考"）图生图出道具状态版。道具版绝不脱离素体版单独文生图，否则同角色两张脸。

### 第 3 步 特殊道具设定图提示词

- 判断标准：推动叙事的关键道具（"内裤真心"的内裤、"喜字枷锁"的囍字；以及"手""胡须"这类以道具展开故事的主题），必须单独出设定图提示词；纯装饰道具不需要。
- 每条 = `道具设定图，多角度：正面、侧面、顶面，` + 形状 + 材质 + 颜色 + 尺寸关系（与人/手的比例）+ 佩戴或使用方式 + 形态约束词（防 AI 画错形态）+ 风格锚点 + `无文字无水印`
- 道具本身就是"主角"（如一只会说话的手）时，按角色三视图标准出道具版角色图，归入人物目录；其余归入道具目录。

### 第 4 步 纯环境场景提示词

- 默认空镜：全片归纳为 4-6 个纯环境场景，多个镜头可共用同一场景（如车厢场景供镜头 1、2 共用）。当前 AI 工具已能稳定区分"场景设定图"与"人物设定图"，所以场景一律出空镜即可。
- 每条 = 环境空镜描述（光线/陈设/氛围） + 风格锚点 + `场景设定图，无人物无角色，无文字无水印`
- 负面提示词在通用负面词库基础上追加：人物, 角色, 动物
- **带角色场景图仅在以下情况出**：需要锁定"角色×环境"的比例/光影/互动（角色靠墙、坐床边、与门窗的空间关系），此时标注使用哪张角色参考图，并保持该场景环境词块与空镜版一致。

### 第 5 步 每镜完整展开提示词

- 结构：场景词 + 动作/构图/运镜词 + 角色锚点 + 道具锚点（涉及道具的镜头）+ 风格锚点
- 全部词块原样嵌入成品句，用户复制即用；严禁出现"+"、"[场景]"等占位符。

### 第 6 步 带时间码配音稿

逐镜旁白文本 + 起止时间码，与分镜逐镜对齐。无旁白的镜头标注（静音/环境音）。语气与第 0 步确认的旁白基调一致。

## 一致性机制（三条叠加，缺一不稳）

1. 固定锚点词块：角色锚点/道具锚点/风格锚点各定稿一段，之后所有镜头原样复制，一个字不改。
2. 参考图锚定：先文生图出角色三视图 → 即梦"角色一致性/角色库"或可灵"多图参考（主体参考，权重拉满）"上传 → 道具版与带角色场景图都以对应参考图图生 → 每镜先文生图出关键帧，确认角色没漂 → 再图生视频。
3. 生成顺序：素体 → 道具版（图生）→ 道具设定图 → 场景空镜 →（必要时）带角色场景 → 关键帧 → 图生视频。不要直接文生视频。

纯文生视频即使锁词块一致性也只有七八成，参考图锚定才是主力。

## 素材目录规范（用户既定习惯）

所有生成素材归入主题文件夹（素材根目录 `D:\视频素材\我的素材\`，已有实例：真心内裤、枷锁、胡须）：

```
<短剧名>\
├── 人物\    角色素体三视图、道具状态版三视图（如 新郎.jpg、枷锁新郎.jpg）
├── 道具\    特殊道具设定图（道具展开型故事）
├── 场景\    纯环境空镜图（命名带场景名，共用场景注明镜头号，如 场景D_村口土路_镜头5_7.jpg）
├── 镜头\    各镜头图生视频片段（用户用即梦/可灵生成后放入，按 镜头1_标题.mp4 命名）
├── 旁白\    配音音频
└── 成片\    剪辑成品与音效素材
```

规则：

1. 提示词包 md 文件也存入主题文件夹（根目录或 `提示词\` 子目录），图、视频、音频、文案同仓管理
2. 文件名用中文描述性命名（如 新娘追赶版.jpg），不叫 img_001
3. 生成图一律去水印：提示词带"无文字无水印"；工具强制带水印时后期处理后再入库
4. 视频片段由用户自行用 AI 工具生成、自行剪辑，本技能只负责提示词与归档规范

## 风格库机制（style-* 技能）

画风以独立技能沉淀在 `~/.qoderworkcn/skills/style-*`，供本技能在第 0 步引用：

- 已有：style-liaozhai-guofeng（聊斋国风水墨工笔，拆解自画心月狐《画皮》；提供通用/夜色/惊悚三套风格锚点变奏 + 配套负面词库 + 仕女/书生/市集/庭院锚点示例）
- 引用规则：风格技能提供"风格锚点词块 + 负面词库 + 角色/场景锚点示例"，本技能负责分镜/三视图/配音稿管线。风格锚点定稿后全片原样复制，一部片最多换 2-3 套变奏（如昼/夜/惊悚），换套只在镜头情绪切换处
- 沉淀规则：用户给新参考（视频/图）时，先获取画面（参考视频可下载抽帧或浏览器截图），按"媒介画法/人物造型/配色体系/光影/构图/运动质感"六维拆解，输出成 style-<风格名> 技能，结构与 style-liaozhai-guofeng 保持一致（含风格来源、使用边界、锚点词块、负面词库、验证方法）

## 常见坑

- 多图直出角色不一致 → 交付提示词 + 参考图锚定，不代生成
- 道具版脱离素体版单独生成 → 同角色两张脸；必须图生图
- "场景"被理解成分镜 → 场景提示词=空镜
- 占位符模板用户无法直接用 → 完整展开
- 道具三视图崩 → 加形态约束词（"罩住头顶"式）
- 道具展开型故事漏出道具设定图 → 第 3 步必做
- 短视频硬套五段式 → 前奏铺垫拖死节奏，观众三秒划走；短视频走钩子+爆点+转场
- 微电影故事平铺无结构/只写高潮 → 先五段式改造，缺段补段（常见缺激励事件或危机）
- 不判断形态一刀切 → 按用户说法分流，没说清就问；两条路径共用生成管线，只有结构改造这一步不同
- 素材散落 → 按 人物/道具/场景/镜头/旁白/成片 归仓
- 平台水印 → 提示词"无文字无水印" + 后期去水印双保险
- 负面词库遗漏 → 每条统一携带（见 reference.md）
